# Скриншоты кейсов

Положите сюда свои изображения с этими именами — они автоматически подхватятся на лендинге.
Пока файла нет, в рамке показывается анимированный скелетон-мокап интерфейса (дашборд / чат бота / лендинг / витрина). Как только реальный файл появится — он плавно перекроет мокап.

| Файл | Где показывается | Рекомендуемый размер |
|------|------------------|----------------------|
| `dashboard.jpg` | Большая плитка — веб-приложение | ~1280×800 (соотношение 16:10) |
| `bot.jpg` | Телефон — Telegram-бот | ~440×880 (вертикальный, 9:18) |
| `landing.jpg` | Плитка — лендинг | ~1280×800 (16:10) |
| `shop.jpg` | Плитка — магазин | ~1280×800 (16:10) |

Форматы: `.jpg`, `.png` или `.webp` (тогда поправьте расширение в `index.html`).
Картинки обрезаются по `object-fit: cover`, так что главное — соблюсти примерные пропорции.
